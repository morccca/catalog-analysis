# Анализ каталога фильмов

Автор: Naumov Pavel. Python 3.12+, [uv](https://docs.astral.sh/uv/getting-started/installation/).

Статистика каталога: средний рейтинг и возраст фильмов, топ-3,
количество фильмов по жанрам и фильмографии актёров.
Все функции и исходные данные находятся в `catalog_analysis.py`.

## Запуск

В каталоге проекта:

```bash
uv sync
uv run catalog_analysis.py
```

Проверка стиля: `uv run ruff check .`.
