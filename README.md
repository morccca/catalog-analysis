# Анализ каталога фильмов

Статистика каталога: средний рейтинг, топ фильмов, жанры и актёры.
Python 3.12+; сторонние библиотеки не нужны.

## Запуск

```bash
python3 main.py
```

`data.py` — исходный каталог, `functions.py` — обработка и отчёт,
`main.py` — запуск.

## Ввод и вывод

Ввод с клавиатуры не требуется. Данные берутся из списка `movies`
в `data.py`: название, год, жанры, рейтинг, длительность и актёры.

Начало вывода:

```text
ОТЧЁТ ПО КАТАЛОГУ
Средний рейтинг: 7.2
Средний возраст фильмов: 8 лет

Топ-3 фильма:
  "The Quiet Algorithm" (2024) — 9.2/10, 1ч 58м, жанры: drama, sci-fi
  "Midnight In Oslo" (2020) — 8.9/10, 2ч 4м, жанры: mystery, thriller
  "The Dune Chronicles" (2021) — 8.6/10, 2ч 35м, жанры: drama, sci-fi
```
